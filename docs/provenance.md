# Provenance

Iron Zapper was developed by Stuart Bowness with AI coding assistance. The source
and bundled project assets are distributed under the repository's [MIT license](../LICENSE).

The implementation uses Apple's system frameworks and has no third-party runtime
packages. Apple SDKs, frameworks, signing services, and developer tools remain
subject to their own terms; they are not relicensed by this repository.

The lightning-bolt artwork was AI-generated for this project and packaged with
Apple Icon Composer. [Resources/ICON.md](../Resources/ICON.md) records its source
assets and generation prompt. The short electrical sound is procedurally generated
by [make-zap-sound.py](../scripts/make-zap-sound.py); no sampled sound library is used.

The `ai.toyo.IronZapper` bundle and helper identifiers reflect the project's origin.
They are preserved to avoid silently changing installed helper registrations.
